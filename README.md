# TV Sources 源管理兼容版

基于 TV 5.5.6 和公开的定制 Media3 构建，增加内置点播/直播源管理。此分支对应已发布的兼容版 APK。

- [下载 APK 与播放器依赖包](https://github.com/AllenHowl/TV/releases/tag/v5.5.6-sources-compat.1)
- [构建及验证说明](BUILDING.md)

提供电视版和手机版 ARM64 Debug APK，最低 Android 7.0（API 24），包名 `com.fongmi.android.tv.sources`，版本 `5.5.6-sources-compat`。两种界面使用同一个包名，按设备选择其中一个；可与原版 `com.fongmi.android.tv` 并存。数据独立保存，不自动迁移原版数据。

内置 56 条点播配置记录和 2 个直播原始地址。支持推荐源、完整目录、搜索、自定义添加、线路选择、首次选源和稍后选择；点播与直播分别记忆，可显式跟随点播配置；保留失败恢复和连续切换保护。

此兼容基线不包含 5.8.4 新增的全部高级播放功能，例如双字幕、部分音视频特效、蓝光/ISO 高级导航和新版独立运行时模块管理。Python 3.10、QuickJS、FFmpeg 与 mpv 已随包编译打包。为防止更新成无关原版，兼容版使用本项目安装包更新。

构建、签名与回归测试已通过；真机安装、遥控器交互和实际播放尚未验证。第三方源的实时可用性需要在设备上确认，目录不将条目标记为已验证可播放。

原项目许可见 [LICENSE.md](LICENSE.md)。播放器依赖的源码提交及原生依赖出处在构建说明和播放器依赖附件中记录。
